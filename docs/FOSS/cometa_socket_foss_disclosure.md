# Open Source Software (FOSS) Components

# Cometa Socket – FOSS Disclosure

This document lists the Free and Open Source Software (FOSS) components that are part of the
**Cometa Socket** service (`cometa/socket`), the WebSocket / Socket.IO server for Cometa.

It covers the Node.js runtime, npm, the Debian base image, and the direct Node.js packages used by
the service.

Full license texts: [LICENSES.md](./LICENSES.md)
