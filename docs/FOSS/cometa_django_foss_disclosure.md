# Open Source Software (FOSS) Components

# Cometa Django – FOSS Disclosure

This document lists the Free and Open Source Software (FOSS) components that are part of the
**Cometa Django** service (`cometa/django`), the API and application backend for Cometa.

It covers the Python runtime, the Debian base image packages required by the service Dockerfile,
and the Python libraries installed for the service.
