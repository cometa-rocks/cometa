# Open Source Software (FOSS) Components

# Cometa noVNC – FOSS Disclosure

This document lists the Free and Open Source Software (FOSS) components that are part of the
**Cometa noVNC** service (`cometa/novnc`), the HTML5 VNC client used for remote browser sessions.

It covers the Ubuntu base image, noVNC, websockify, and supporting packages.
