# Open Source Software (FOSS) Components

# Cometa Crontab – FOSS Disclosure

This document lists the Free and Open Source Software (FOSS) components that are part of the
**Cometa Crontab** service (`cometa/crontab`), the Alpine-based cron helper used by Cometa.

It covers Alpine Linux, BusyBox crond, curl, jq, and the libraries linked into those tools.
